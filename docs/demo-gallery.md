# Demo Gallery

This page is generated by `pnpm demo:gallery`.

The gallery intentionally renders polished `examples/showcase/` specs from `examples/manifest.json`. Proof fixtures live under `examples/proof/actions/` and `examples/proof/variants/`, and full-flow QA lives under `examples/assurance/long-demo/`; those suites are discoverable with `demo-machine examples list --type proof`, `demo-machine examples list --type assurance`, or `demo-machine examples show <slug>`, but they are not gallery entries. Validate the manifest-backed specs with `pnpm examples:validate`, and run `pnpm video:assure` after rendered MP4 outputs exist to check for blank frames, frozen spans, and large visual jumps.
