# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.2.x   | Yes       |
| < 0.2   | No        |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report them via [GitHub private security advisories](https://github.com/45ck/demo-machine/security/advisories/new).

We will acknowledge your report within 7 days and work with you on a coordinated disclosure timeline.
